Reading this reference

Keys are listed as Active Effect paths (system.hp.value). In roll formulas, drop system. and prefix @ (@hp.value). In code, use actor.system.hp.value.

Derived fields are recalculated every time the actor prepares. They can be read in formulas but not written: an update or Active Effect on them is discarded. Target the input instead:

Instead of Target
system.ac.value system.ac.mod
system.scores.str.mod system.scores.str.value
system.movement.encounter system.movement.base
system.encumbrance.pct system.encumbrance.max

Character

Hit points

Key Default Notes
system.hp.value 20 Current
system.hp.max 20 Maximum
system.hp.hd "1d8" Hit dice, e.g. "2d8+1"

Armour class

Both descending (ac) and ascending (aac) are always maintained; the ascendingAC setting picks which is shown and rolled against.

Key Default Notes
system.ac.mod 0 Flat modifier. Use this to adjust AC. Mirrors aac.mod
system.aac.mod 0 Mirrors ac.mod

Derived: ac.value (armour - shield - mod, or naked with no armour), ac.base (9), ac.naked (9 - dex.mod), ac.shield, and the aac equivalents (base 10, values added instead of subtracted). ac and aac are each derived from their own field on the armour, so they disagree if the armour's ac/aac values don't sum to 19.

Attack

Key Default Notes
system.thac0.value 19 THAC0. Kept at 19 - bba on update
system.thac0.bba 0 Base attack bonus (ascending AC)
system.thac0.mod.melee 0 Melee attack bonus (Tweaks)
system.thac0.mod.missile 0 Missile attack bonus (Tweaks)

The attack roll is 1d20 [+ bba if ascending] + str.mod or dex.mod + thac0.mod.<melee|missile> + weapon bonus. Melee damage adds str.mod and thac0.mod.melee; missile damage doesn't.

meleeMod and rangedMod are derived display values for the sheet only - the roll doesn't read them.

Saving throws

system.saves.<death|wand|paralysis|breath|spell>.value - integer, unset (null) until a class is applied. Roll 1d20 at or above. Magic-based saves add scores.wis.mod and details.magic.bonus.

Ability scores

system.scores.<str|int|wis|dex|con|cha>.value - default 0 (so a blank character has -3 modifiers). Each also has a .bonus field that is stored but not used by the system. Scores aren't type-checked on write.

Derived per score:

Key Notes
scores.<ability>.mod Standard OSE modifier, -3 to +3
scores.str.od Open doors, 0-5 in 6
scores.int.literacy, scores.int.spoken i18n keys, not numbers - localize before display
scores.dex.init, scores.cha.npc Capped modifier, -2 to +2
scores.cha.loyalty, scores.cha.retain Retainer loyalty (mod + 7) and max retainers (mod + 4)

Movement

Key Default Notes
system.movement.base 120 Feet per turn

Derived: movement.encounter (base / 3) and movement.overland (base / 5). When config.movementAuto is on, base itself is reduced by encumbrance (x0.75, x0.5, x0.25 at each breakpoint, 0 when over maximum).

Initiative

Key Default Notes
system.initiative.value 0 Base
system.initiative.mod 0 Flat (Tweaks)

Derived: init = value + mod + scores.dex.init, or 0 under group initiative. The tracker rolls 1d6 + @init.

Exploration skills

Roll 1d6 at or under. 0 is rejected - use null for no chance.

Key Default Skill

system.exploration.od 2 Open doors
system.exploration.sd 1 Secret doors
system.exploration.ft 1 Find traps
system.exploration.fg 1 Forage
system.exploration.hn 1 Hunt

exploration.od is unrelated to the derived scores.str.od.

Encumbrance

system.encumbrance.max is the only input - default 1600 (9 for item-based). Everything else is derived and depends on the world's encumbranceOption setting:

  • All variants: value, pct (0-100), encumbered, enabled, variant, steps, atFirstBreakpoint / atSecondBreakpoint / atThirdBreakpoint.
  • complete / detailed: coin weight, breakpoints at 25%, 37.5%, 50%.
  • basic: breakpoints come from heaviest equipped armour and treasure carried; adds overTreasureThreshold, overSignificantTreasureThreshold.
  • itembased: item slots; adds equippedValue / packedValue, equippedPct / packedPct, weightMod, and related fields.

Spells

Key Default Notes
system.spells.enabled false
system.spells.<level>.max 0 Slots per level - write here

Read slots from @spells.slots.<level>.max and @spells.slots.<level>.used - @spells.1.max is always undefined. spells.spellList holds owned spells grouped by level.

Computed properties

Read-only values the system computes, directly on actor.system (not under details). Usable as @name in formulas.

  • usesAscendingAC - the ascendingAC setting
  • init - see Initiative
  • isNew - all ability scores are 0
  • isSlow - any equipped weapon is slow
  • carriedTreasure - total value of treasure carried
  • Item lists: weapons, armor, abilities, items, treasures, containers, spellList

Monster

Monsters use a smaller model. They have no system.scores (scores.str.mod throws), no derived AC, and no exploration, meleeMod, rangedMod, details.class, details.title, details.level, or details.magic.bonus.

Same as characters: hp, thac0, saves, spells, languages, retainer, initiative (but init has no DEX term). THAC0 and save tables by HD are in CONFIG.OSE.monster_thac0 and CONFIG.OSE.monster_saves, but aren't applied automatically.

Armour class

system.ac.value and system.aac.value are stored directly (default 0); write either and the other is kept at 19 - x. Armour items don't affect them. ac.mod / aac.mod exist but aren't applied.

Movement

system.movement.base (default 120) is never reduced - monsters always use the disabled encumbrance variant. encounter and overland are derived as for characters. system.details.movement is free text for display only.

Computed properties

Read-only values the system computes, directly on actor.system (not under details). Usable as @name in formulas.

  • usesAscendingAC, init - as for characters
  • isNew - all saves are unset
  • isSlow - true only if all of the monster's weapons are slow. Unlike characters, it ignores whether they're equipped
  • attackPatterns - weapons and abilities grouped by system.pattern
  • Item lists as for characters, sorted by name (no spellList - use spells.spellList)

Items that affect actors

Armour sets character AC. Only equipped items count, and only the first armour and first shield found.

Key Default Notes
system.ac.value 9 AC this armour sets (not a bonus)
system.aac.value 10 Keep equal to 19 - ac.value
system.type "light" "light", "heavy", or "shield"
system.equipped false

system.itemslots drives item-based encumbrance. Default 1 on weapons, armour, and containers; 0 on plain items. Slots used are ceil(itemslots * quantity).
